\begin{abstract}

Autonomous agents transact at rates and volumes that exceed the capacity of ledger-based settlement. We present Unicity, a blockchain architecture without a shared ledger. On-chain state is limited to the data required to prove that a given asset state has been spent exactly once. Assets are self-contained cryptographic objects stored off-chain, transferred directly between parties, and validated by their recipients. Throughput scales horizontally by adding independent shards. Transactions are private to their participants, and settlement is final within seconds. Recursive aggregation combines every shard's per-round consistency proofs from genesis into a single constant-size proof. Any party can verify this proof against the network's genesis configuration alone, without trusting validators for the correctness of the recorded history. The platform provides programmable ownership, token standards with locally verifiable issuance rules, trustless bridging of external assets, and an enshrined EVM partition for applications that require shared, ordered state.

\end{abstract}

\subsection*{TL; DR}

\begin{itemize}
    \item \textbf{Consensus Layer:}
    The Byzantine fault tolerant core maintains the certified shard roots and the validator trust base, without a blockchain. It verifies each shard's consistency proof and issues certificates with single-round deterministic finality. Decentralized by Proof of Stake.

    \item \textbf{Aggregation Layer:}
    This public infrastructure maintains an append-only sharded radix Sparse Merkle Tree. Clients submit a cryptographic identifier of the state they are spending. The layer provides inclusion proofs for spent states, non-inclusion proofs for unspent states, and a certificate binding those proofs to the single valid history. Shards partition the key space by prefix, prove their transitions independently, and split as demand grows.

    \item \textbf{Trustless Aggregation:}
    Recursive aggregation combines every per-round consistency proof from every shard since genesis into one fixed-size proof. Verification establishes, under cryptographic assumptions alone and without assumptions about the validator set, that no recorded state was deleted, modified, or recorded twice.

    \item \textbf{Tokens:}
    A token is a self-contained ledger containing its genesis, transfer history, and certificates proving each step. A recipient verifies it without consulting external state. Issuance rules are fixed in the token's type and rechecked by every recipient. Succinct proofs bound the size of the stored history.

    \item \textbf{Programmability:}
    Ownership generalizes to predicates: spending conditions evaluated off-chain by the transaction participants. Token types can define state machines that every verifier reruns. These support automated market makers without an operator or other trusted party.

    \item \textbf{Enshrined EVM:}
    One certified partition runs an account-based execution environment for governance, staking contracts, and the native currency. Consensus primitives are callable from contracts, so settlement between the two execution models shares a single root of trust.

    \item \textbf{Bridging:}
    Assets from external blockchains are locked in a vault and represented by tokens minted against a backing proof that every recipient rechecks. Redemption requires burning the Unicity token and presenting a succinct validity proof that the vault verifies at constant cost. Neither direction requires a trusted operator, a committee, or a challenge window.
\end{itemize}
